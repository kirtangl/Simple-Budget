# Simple Budget – Coles button

Coles doesn't let automatic price checkers in, so this extension gets Coles prices in your own
browser instead, only when you press it: it opens Coles in a tab, searches for what's on your
Simple Budget lists a few seconds apart, and sends the prices back. If Coles shows a check, it
stops and shows you the Coles tab. Nothing here tries to get around one.

Set up (once per computer): download it from Simple Budget (Shopping → Check prices → Coles
button), unzip it, go to brave://extensions (or chrome://extensions), turn on Developer mode, press
Load unpacked and pick this folder. Click its icon and put in Simple Budget's address and key.
